# 质量图冲突与实际轨迹的关系

`scripts/envpack/audit_quality_exposure.py` 用于把整场 feature 诊断中的
nodata/hole/water 标记定位到实际录制主体。它不改输入，不启动渲染器或模型，
不自动判定地形违法，也不授予场景/任务准入。

```sh
python scripts/envpack/audit_quality_exposure.py \
  --event /frozen/plans/v1.diagnostic --world /frozen/world \
  --out /new/quality-exposure
```

输入要求磁带完整且摘要与 manifest 一致、世界版本一致，质量栅格及描述文件
与 world.json 声明一致。人物使用与现有物理检查共用的姿态占地包络，核对其
记录资产与当前目录相符，所有消费文件记录摘要并在结束时复核。

每个已录制时刻、每个地面可见主体均检查完整有向矩形，而非仅检查中心或四角。
最近邻距离只作保守粗筛；四轴分离测试决定矩形与标记网格的交集，包括身体内部
的小标记区域与边界接触。栅格外未知区域独立统计，藏在车内的乘员由车辆占地覆盖。
结果包含所有主体的检查帧数、各标记帧数，以及 exposures.npz 中完整的命中姿态。

这是按录制频率检查的二维包络，不是帧间扫掠体或水域用途现场勘测。
命中粗分辨率质量图需要结合视觉、真实几何和语义解释；无命中也不能证明
整个环境不存在质量问题。原物理/生活门槛和 query 验证不变。

验证：400 个随机矩形与独立 Shapely 多边形求交逐个一致；覆盖内部标记、
旋转、边界、空图、图外和无效输入。真实二进制磁带夹具验证逐帧计数、隐藏帧、
只读及输入变化拒绝。连同已有身体测试 30 项通过，3 项本地资产依赖测试跳过；
它们不替代新场景的原生执行结果。
